# TETRIS

Uma versão do clássico Tetris feita em HTML, CSS e JavaScript puros, em um único arquivo — sem dependências, sem build, sem frameworks. Visual moderno em estilo neon/glass e totalmente responsivo, com suporte a teclado e a controles por toque.

[Jogar agora](https://jonasdamaia.github.io/basicgame/)

## Demonstração

Abra o arquivo `index.html` diretamente no navegador ou publique-o com o GitHub Pages para jogar online.

## Funcionalidades

- Sete peças clássicas (I, O, T, S, Z, J, L), cada uma com cor e brilho próprios
- Peça fantasma (ghost piece), mostrando onde a peça atual vai encaixar
- Pré-visualização da próxima peça
- Pontuação, nível e contagem de linhas, com aumento progressivo de velocidade
- Pausa e tela de fim de jogo com opção de reiniciar
- Layout responsivo: o tabuleiro se ajusta ao tamanho da tela
- Controles por toque exibidos automaticamente em dispositivos com tela sensível ao toque

## Como jogar

| Ação | Teclado | Toque |
|---|---|---|
| Mover para a esquerda | `←` | Botão ◀ |
| Mover para a direita | `→` | Botão ▶ |
| Girar peça | `↑` | Botão ⟳ |
| Queda suave | `↓` | — |
| Queda rápida | `Espaço` | Botão "Queda rápida" |
| Pausar / continuar | `P` | Botão "Pausar" |

## Como rodar localmente

Não há dependências nem processo de build. Basta abrir o arquivo `index.html` em qualquer navegador moderno
